Chat Restore

Open a WhatsApp export and read it back the way it was.

Nothing is uploaded. The file is opened inside this browser tab and never leaves the device — there is no server, no account, nothing stored anywhere.
How to export a chat

iPhone: open the chat → tap the contact name at the top → scroll down → Export Chat → Attach Media → Save to Files. You get one .zip.

Android: open the chat → ⋮ menu → More → Export chat → Include media → save it. You get one .zip.

Give this page the whole .zip — photos, videos and voice notes come with it. A bare .txt works too, just without media.
